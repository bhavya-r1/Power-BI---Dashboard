# Performance Tracker Dashboard

## Overview

The Performance Tracker Dashboard is an interactive Power BI solution designed to monitor key performance indicators (KPIs), analyze trends, and support data-driven decision-making. The dashboard combines data visualization, data modeling, and DAX calculations to provide meaningful business insights in a clean and user-friendly interface.

---

## Project Objectives

- Monitor business performance through key metrics.
- Identify trends and patterns over time.
- Enable interactive data exploration using filters and slicers.
- Support informed business decisions with visual analytics.

---

## Dashboard Features

- KPI Cards for performance monitoring
- Interactive slicers and filters
- Trend analysis using line and bar charts
- Comparative performance analysis
- Dynamic visualizations
- Clean and intuitive dashboard design

---

## Technologies Used

| Technology | Purpose |
|------------|---------|
| Power BI Desktop | Dashboard Development |
| Power Query | Data Cleaning and Transformation |
| DAX | Measures and Calculated Columns |
